# UI i responsywność

Scenariusz: podstawowa kontrola responsywności
- Kroki: otwórz aplikację w widoku desktop, tablet, mobile (devtools lub Playwright `devices`).
- Oczekiwane: pola i przyciski czytelne; elementy nie wychodzą poza ekran; menu zastąpione hamburgerem gdy potrzeba.

Wskazówki:
- Użyj gotowych projektów Playwright dla urządzeń lub `page.setViewportSize()`.
